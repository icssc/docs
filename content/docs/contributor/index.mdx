This section covers the contributing process, organizational principles, and local setup for anyone interested in working on ICSSC's projects.

## Making your First Contribution
To start, anyone new to web development or unfamiliar with the basic technologies in our [toolchain](/docs/contributor/common/toolchain) should first read our [development introduction](/docs/contributor/common/development-guide/introduction). This will walk you through the technologies we use.

Once you're familiar with our toolchain, you can make your first contribution!
1. Read the [Contributor Guidelines](/docs/contributor/common/guidelines), which are shared by all projects
2. Reference the getting started guide for the project you're most interested in (see below) and get it set up locally
3. Visit the project's GitHub repository, find an issue that interests you, and let the team know that you'd like to take it on
